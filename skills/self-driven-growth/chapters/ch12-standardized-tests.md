# 第一编·第12章：SAT、ACT 和另外四个字母

## Core Idea

标准化考试可以提供信息，却不应成为孩子价值、家庭情绪或教育路径的唯一裁判。围绕考试的健康做法是降低身份威胁、建立可选择的准备计划，并保留多种未来路径。

## Frameworks Introduced

- **N.U.T.S. 用于考试压力**：新奇、不可预测、评价威胁和低控制感会让考试从测量变成威胁。
  - When to use：备考焦虑、逃避、过度刷题或一次失利后崩溃。
  - How：增加熟悉度和模拟；明确可控准备项；将分数与人格价值分离；准备多个选择。
- **信息而非身份**：把成绩视作某时点、某种格式下的有限数据。
  - When to use：家长或孩子把高分当作唯一成功证明时。
  - How：同时讨论兴趣、学习环境、经济现实、成长与替代申请路径。

## Key Concepts

- **考试焦虑**：评价情境引发的生理和认知干扰。
- **完美主义**：把不犯错与值得被认可绑定的倾向。
- **准备计划**：可控、节奏适当、保留睡眠与生活的复习安排。
- **替代路径**：不把一场考试或一所学校视为唯一机会。

## Mental Models

- 考试只是要解决的问题，不是要证明“我是谁”的审判。
- 若备考明显破坏睡眠、关系或心理健康，计划本身需要调整。

## Anti-patterns

- **成人接管全部备考**：会把孩子的教育目标变成父母的焦虑项目。
- **用比较制造动力**：通常增加自我威胁，未必增加有效学习。

## Worked Example

孩子因模拟考失常想放弃。成人先不分析错题，而是确认失望和害怕；随后共同区分可控项（题型熟悉、睡眠、复盘、是否再考）与不可控项（他人分数、当天题目）。孩子选择下一轮节奏，并同时列出不依赖单一分数的选择。

## Key Takeaways

1. 考试准备应保护健康、选择权和长期学习能力。
2. 降低评价威胁比重复强调重要性更能改善发挥。
3. 多条路径使目标更可持续。
