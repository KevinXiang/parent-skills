- 指定主题：如“抢玩具”“轮流”“发脾气”“害羞”“公平”或“后果”，先查主题索引，再读对应章节。

## 核心框架与思维模型

### 1. ICPS：教孩子“如何思考”，不是替孩子决定“该怎么做”

“我能解决问题”（I Can Problem Solve，ICPS）关注人际问题的思考过程。成人不急着宣布正确答案、解释道理或替孩子调解；而是帮助孩子识别问题、看见感受、生成办法、预估后果。目标是让孩子在成人不在场时也能暂停冲动、维护自己并兼顾别人。

当孩子抢、打、哭闹、退缩或执拗时，先假定行为是在解决一个真实的、但尚未说清的问题。不要把成人所见的“问题行为”直接当作孩子的问题；先问“发生了什么？”和“你想要什么？”。同一件事可能有不同的视角。

### 2. 完整 ICPS 对话：四个必经环节

按这个顺序提问；孩子熟练后可以缩成一两句提示。

1. **明确问题**：发生了什么？谁想要什么？不要急着裁定谁对谁错。
2. **理解感受**：你有什么感觉？对方可能有什么感觉？不确定时看、听，或直接问。
3. **想不同办法**：这是一种办法；还能想一个不同的办法吗？先求数量与差异，不急着评判。
4. **预估后果并选择**：如果这样做，可能会发生什么？这会让谁有什么感觉？它真的解决问题吗？若不理想，再想别的办法。

### 3. 词汇是思维的工具，不是背诵内容

对学龄前和低龄孩子，先在轻松游戏中练习关键概念，再用于真实冲突。词汇为孩子提供原先没有的思考支架：

| 概念 | 之后能支持的思考 |
|---|---|
| 是／不是；和／或者；一些／所有 | 区分事实、选择与范围；避免“只有一种办法” |
| 相同／不同 | 不同人可有不同喜好；同一问题可有不同办法 |
| 之前／之后；现在／以后 | 看见顺序、等待与行为后果 |
| 合适／不合适的时间或地点 | 判断请求、行为与安全是否适时适地 |
| 如果／那么；可能／或许；为什么／因为 | 建立因果、概率与不确定性；不把猜测当事实 |
| 公平／不公平 | 同时尊重自己的权利和他人的权利 |

### 4. 感受不是读心：看、听、问

先用表情、声音和直接询问三种途径了解感受。孩子要学会：不同的人面对同一事件可能感觉不同；“可能／或许”表示不确定；最可靠的办法往往是问对方。优先建立开心、伤心、生气等基础词；“骄傲、沮丧”等复杂词要等孩子能理解后再引入。羞怯或语言较少的孩子可先用二选一、点头或指图回应。

### 5. 头脑风暴阶段不审判；评估阶段才看好坏

生成办法时，承认每个与问题相关的主意，记录下来，区别“新的类别”与只是换词的同一办法。即使孩子说抢、威胁或哭来操纵，也先让他说明“这怎样解决问题”；不要在生成阶段训诫而缩窄思路。进入后果阶段后，再用“如果这样，别人会怎样？还可能发生什么？这真能解决吗？”让孩子自行发现负面代价和替代方案。

### 6. 平静是对话的前提，练习在没有危机时发生

成人或孩子情绪过强时，先表达边界、暂停和安抚；不要在失控时强行进行完整对话。平时通过餐桌、购物、故事、玩偶、角色扮演和日常选择练习，真实冲突中才更容易调用。练习要贴合孩子能理解的概念，也要允许孩子把游戏带得有趣、重复和主动。

### 7. 评价成功：成人少替孩子想，孩子多能自己复盘

不要只以“孩子这次是否立刻听话”衡量。更重要的迹象包括：孩子会说出自己的问题与感受、会问别人感受、能提出不同办法、能在办法失败后再试、能为自己与他人的权利找平衡。家长的进步是从命令、建议和解释，转向有耐心的提问、倾听与复盘。

## Scope & Limits

本 skill 提炼的是本书的 ICPS 方法，主要适用于日常人际冲突、适应与社会问题解决。不要把它用作诊断、羞辱孩子“不会思考”的标签，或在孩子/成人明显失控时进行说教。涉及持续攻击、严重退缩、创伤、虐待或自伤风险时，安全和适当的专业支持优先。
