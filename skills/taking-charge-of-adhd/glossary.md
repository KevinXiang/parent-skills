# 术语表

**ADHD（注意缺陷/多动障碍）** — 以注意、冲动、活动水平与自我调节困难为核心，并造成实际功能损害的神经发育障碍；诊断须由合格专业人员完成（Ch 1, Ch 5, Ch 8）。

**功能损害** — 症状对家庭、学习、同伴、健康或安全等日常活动造成的可观察影响；比单一特质更关键（Ch 5, Ch 7）。

**共病** — 与 ADHD 同时出现、需要单独识别和支持的学习、情绪、行为、睡眠或其他困难（Ch 5, Ch 8）。

**工作记忆** — 在短时间内保存并运用信息来指导行动的能力；可用清单、视觉提示和流程卡外化支持（Ch 2, Ch 9）。

**执行功能** — 服务于抑制、计划、组织、时间管理、目标维持和自我监控的一组能力（Ch 2）。

**行为抑制** — 暂停即时反应、等待、思考后果并选择下一步的能力（Ch 1, Ch 2）。

**多模式支持** — 将行为、教育、环境、家庭、健康和必要的临床治疗组合，而非押注单一办法（Ch 9）。

**每日报告卡** — 教师就少量具体目标在一天中多次反馈的简短记录，可与家庭反馈相连（Ch 17）。

**代币/积分制度** — 把可观察行为与即时积分、代币或特权相连，再兑换事先约定的奖励（Ch 11, Ch 17）。

**反应代价** — 对明确、已知的不当行为扣除部分积分或特权；应有限、可理解且建立在大量正向强化之上（Ch 11）。

**正向强化** — 在目标行为出现后立即给予具体注意、认可、活动或其他有价值结果，以提高其再次出现概率（Ch 11, Ch 17）。

**计时隔离（time-out）** — 暂时失去获得强化机会的短时后果；不应羞辱、隔绝或替代整体行为计划（Ch 11, Ch 17）。

**表现发生点** — 行为真正需要被完成的时间和地点；提示与反馈靠近这里更有效（Ch 2, Ch 17）。

**过渡** — 从一个任务、地点或活动转向另一个的时刻；提前提示、复述规则和可见时间支持有助于降低困难（Ch 12, Ch 17）。

**时间外化** — 用时钟、倒计时、视觉日程或分步期限，把抽象时间变得可见可操作（Ch 2, Ch 9, Ch 14）。

**问题解决七步法** — 界定问题、转为积极目标、列选项、评估、选择、协商、执行并复盘（Ch 12）。

**“只有……才能……”策略** — 先完成必要责任，再获得后续活动的清楚顺序表达；避免模糊讨价还价（Ch 12）。

**牧羊人而非工程师** — 父母提供支持、结构、优先级和保护，而非试图控制或“修复”孩子的一切（Ch 9）。

**合理期待** — 标准与孩子发展、功能能力、所获支持相匹配；不等于放弃边界或责任（Ch 5, Ch 14, Ch 18）。

**家庭—学校协作** — 围绕同一少量目标、统一反馈语言并定期复盘的合作方式（Ch 16–18）。

**共同决策** — 家长、孩子（适龄时）和临床专业人员共同讨论目标、风险、偏好、监测与随访，而非自行用药（Ch 19, Ch 20）。

**监测** — 用基线、目标行为、学校反馈、健康观察和专业随访来判断支持是否有效或是否需要调整（Ch 8, Ch 17, Ch 19）。
