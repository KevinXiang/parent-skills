# 第11章：正面管教的综合应用

## Core Idea

方法只有进入高频日常场景才会变成能力。本章把前面的原则放进浴室、早晚常规、手足冲突、课堂管理和选择安排中：成人先管理自己的参与方式，再决定需要教什么、由谁负责、何时暂停。

## Frameworks Introduced

### 成人退一步

当成人已经失去冷静，可以礼貌地暂时退出：“我现在需要几分钟恢复平静，之后我们继续解决。”退出不是冷战、威胁离开或让孩子独自承担危险，而是主动保护关系和理性。

### 由成人决定自己做什么

面对拒绝，成人不必反复命令孩子。可以决定自己的行动：把危险物品收好、暂停共同活动、重新安排时间、提供有限选择。行动要与问题相关，不以羞辱孩子为目的。

### 常规、信号与选择

- 与孩子共同画出早晨和睡前流程。
- 用眼神、手势、卡片等非语言信号减少唠叨。
- 给年龄适合的选择，而且两个选项都能接受。
- 使用“你完成 X，然后我们做 Y”的明确顺序，不把它说成神秘奖励。

### 手足冲突

无安全风险时，成人可以避免立即当裁判，给双方相同的选择并退出争夺；有攻击、危险或责任边界时，成人必须介入保护。事后再用问题解决流程恢复关系。

## Key Concepts

- 不介入不等于忽视；成人要持续观察并准备在安全风险出现时行动。
- 选择应扩大责任，不应让孩子选择是否遵守基本安全规则。
- 零花钱可以作为家庭生活中的资源练习，不宜随意和好行为绑定成奖励或惩罚。
- 同样的回应需要根据孩子年龄、能力、神经发展与家庭文化调整。

## Anti-patterns

- 把“退出权力斗争”变成冷漠不理。
- 给出表面选择：“你现在做，还是我打你之后做？”
- 对所有手足冲突都不介入，错过保护时机。
- 用流程图增加控制，却不让孩子参与设计。

## Worked Example

两个孩子争浴室。成人先确认没人受伤，然后说：“浴室使用需要轮流。你们可以自己用计时器安排，或者我来安排顺序；如果继续争抢，浴室门口将暂停使用，等你们准备好轮流。”成人不争论谁更有理，提供两个可接受方案，并清晰说明自己的保护行动。

## Key Takeaways

1. 方法的关键时刻是成人被触发时。
2. 选择成人自己的行动，减少无效命令。
3. 常规、信号、有限选择和安全介入共同构成日常系统。
