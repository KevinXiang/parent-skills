# 实践篇·第3章：不在沟通中传递焦虑

## Core Idea

家长可在看见风险时仍传递信心：清楚表达关切、保持温暖与尊重、相信孩子能参与解决。恐慌、威胁和反复盘问会把成人的焦虑变成孩子的新负担。

## Frameworks Introduced

- **关切 + 信心 + 选择**：表达你观察到的风险，同时告诉孩子你相信他有能力一起处理，并邀请他参与下一步。
  - When to use：安全担忧、情绪低落、社交压力或成绩变化。
  - How：描述事实而不贴标签；说明愿意陪伴；询问他认为什么会有帮助。
- **家是避风港**：家庭应是孩子能恢复、说实话和犯可修复错误的地方。
  - When to use：孩子已经受挫、羞耻或害怕被责备时。
  - How：先降低惩罚威胁，再讨论责任、修复和资源。

## Key Concepts

- **信心语言**：传达“我相信你能学会/能求助”，不是保证结果。
- **共调节**：成人稳定状态帮助孩子稳定。
- **关切表达**：就具体行为和影响说话，不把孩子定义为问题。

## Anti-patterns

- **灾难预言**：把当前行为直接等同于毁掉前途。
- **把担忧伪装成批评**：孩子听到的是不被信任，而非被关心。

## Worked Example

发现孩子近期常缺课。成人说：“我注意到这周有三天没去学校，我很在意你的状态，也相信我们能弄清原因。你愿意先告诉我最难的部分，还是想让我陪你约老师或专业人士谈谈？”

## Key Takeaways

1. 关切要具体，信心要可信，选择要真实。
2. 孩子失衡时，成人的镇定本身就是干预。
3. 若涉及自伤、他伤或即时安全风险，应立即寻求当地紧急和专业支持。
