# 第8章：班会

## Core Idea

班会不是教师发布通知，也不是全班审判某个孩子，而是一个让学生持续练习感谢、倾听、表达、换位、头脑风暴和民主解决问题的结构。教师仍然负责安全和教学环境，但不垄断判断权。

## Frameworks Introduced

### 班会的八个要素

1. 围成圈，建立平等参与的空间。
2. 进行感谢或欣赏。
3. 使用公开议程。
4. 练习沟通和倾听。
5. 让每个人都拥有独特的参与方式。
6. 通过角色扮演和头脑风暴练习技能。
7. 探索行为背后的四种错误目的。
8. 共同提出非惩罚性解决方案。

### 班会节奏

小学阶段可每天或每周三至五次，视班级情况而定。问题进入议程后，通常先留出至少一天冷静期；拖延超过数天则可能失去相关性。固定主持、记录、发言顺序等角色，帮助学生形成可预测的结构。

## Key Concepts

- 感谢环节让班级从“找问题”开始转向“看见贡献”。
- 议程中的问题属于共同学习材料，不是教师秘密处理的个案。
- 可以先进行两轮表达：第一轮每人说感受，第二轮再进入方案。
- 受影响的学生应参与选择方案；教师不应充当唯一裁判。
- 角色扮演让学生练习替代行为，而不是只谈抽象道理。

## Mental Models

### 班会是技能训练场

问题发生 → 记录 → 冷静 → 表达 → 头脑风暴 → 选择 → 试行 → 复盘。班会的价值不只在一次解决，更在于让学生反复走完这个流程。

### 教师是主持人和守护者

教师负责保护安全、维持结构和阻止羞辱，但把思考、表达和选择机会逐步交给学生。

## Anti-patterns

- 班会变成教师训话或表扬先进。
- 当天发生冲突当天逼迫孩子公开解释。
- 让全班投票决定谁该受罚。
- 只问“谁做错了”，不给方案练习。

## Worked Example

学生在小组活动中不断插话。教师让问题进入议程，第二天先请每人说这种互动让自己有什么感受，再请小组头脑风暴：发言卡、轮流主持、记录员提示、暂停信号等。小组选择“每人两张发言卡 + 非语言提示”，试用一周后复盘效果。

## Key Takeaways

1. 班会把正面管教从成人命令变成集体练习。
2. 先感谢、表达和理解，再进入问题解决。
3. 结构稳定比一次会议的完美更重要。
