# 第一编·第2章：顾问型父母

## Core Idea

父母应从“推动者/老板”转为孩子的顾问：关心、提问、提供信息和支持，但不替孩子承担本应由孩子面对的学习、社交与选择后果。

## Frameworks Introduced

- **顾问型父母**：像优秀顾问一样帮助当事人看清问题、选定目标、评估代价与资源；改变仍由当事人决定。
  - When to use：作业、选课、同伴冲突、拖延等非紧急问题。
  - How：先问“这是谁的问题”；征得同意后再给建议；结尾把责任与下一步交回孩子。
- **问题归属**：孩子的问题不等于父母必须接管的问题。
  - When to use：成人因孩子表现而焦虑、想立刻救场时。
  - How：区分安全/法律/他人权利等必须介入事项，与可让孩子学习承担的日常问题。

## Key Concepts

- **影响力**：凭信任、理解和可信建议推动改变，不是凭权力迫使服从。
- **内驱力**：孩子认为目标属于自己、努力有意义时更可能产生的持续行动。
- **自然结果**：行为在现实中产生的后果；它不同于成人为了让孩子痛苦而附加的惩罚。
- **救场**：成人替孩子移走可学习承担的后果。

## Mental Models

- 用“我可以怎样支持你？”代替“你为什么还不去做？”。
- 顾问不等于冷漠：先建立联结，再讨论选择、风险和帮助。

## Anti-patterns

- **反复说教未来后果**：把孩子的生活变成父母焦虑的项目，容易激起抵抗。
- **未获邀请就给方案**：信息可能正确，但在孩子尚未被理解时，建议会被听成控制。

## Worked Example

孩子拖着不写作业。成人先平静地说“我看见你似乎被这件事卡住了；你想自己处理，还是一起想想？”若孩子愿意，讨论他想达成什么、障碍是什么和可选办法；若他暂不愿意，只说明可提供的帮助和现实截止时间，不把晚上的每一分钟接管过来。

## Key Takeaways

1. 问题归属清楚，才能给出既温暖又不越界的支持。
2. 有效建议以倾听和同意为前提。
3. 父母的长期目标是让孩子学会管理自己的生活，而非把今天每件事做对。
