# 术语表

**保护性强制力**——为防止即时伤害、保护生命或安全而采取的限制行动；目标是保护，不是让对方受苦或屈服（Ch 12）。

**道德主义评判**——把不符合个人价值或需要的人、行为贴为“坏、自私、懒、没教养”等本质标签的表达（Ch 2）。

**感受**——人当下的情绪或身体体验，如害怕、失望、兴奋、疲惫；“我觉得你不尊重我”是对他人的判断，不是感受（Ch 4）。

**感激三要素**——说清楚对方做了什么、这满足了自己什么需要、自己因此有什么感受；不把赞赏用作操控（Ch 14）。

**观察**——能指向具体时间、行为和情境的描述，尽量不混入评价或推断（Ch 1, Ch 3）。

**静默临在**——不急于建议、解释或安慰，以专注与停顿陪伴对方的经验（Ch 8）。

**同理心**——专注理解对方的观察、感受、需要和请求；不是同意、纵容或替对方解决（Ch 7, Ch 8）。

**内在评判**——“我应该/他不该”一类让人陷入羞愧、愤怒或控制的自动想法；可转译为自己重视的需要（Ch 9, Ch 10）。

**疏离生命的语言**——比较、道德评判、推卸责任、强迫和以奖惩操控等，使人远离彼此需要与选择的沟通习惯（Ch 2）。

**请求**——说清楚希望对方现在可观察、可执行的正向行动，并愿意听见拒绝与协商（Ch 6）。

**请求与要求**——能否接受对方说“不”是区分关键；拒绝后若羞辱、威胁或惩罚，原本的请求就成了要求（Ch 6）。

**需要**——所有人可能共同重视的生命价值，如安全、尊重、休息、玩耍、合作、自主、理解和贡献；不是让某个人做某件事的策略（Ch 1, Ch 5）。

**四要素**——观察、感受、需要、请求；既用于表达自己，也用于倾听他人（Ch 1）。

**自我同理**——把注意力带回自己的感受、需要与可选择行动，以理解替代自责或自动反应（Ch 9）。

**由衷的给予**——基于自愿、关爱与贡献的给予，不出于害怕、羞愧、内疚或交换回报（Ch 1）。
