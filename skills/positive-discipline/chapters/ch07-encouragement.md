# 第7章：鼓励

## Core Idea

鼓励帮助孩子把评价中心放回自己：我付出了什么努力？我学会了什么？我还能尝试什么？表扬若过度依赖成人评价，孩子可能只追求“被说好”，害怕犯错或等待外部认可。鼓励不是少说好话，而是更具体地描述努力、策略、进步和贡献。

## Frameworks Introduced

### 鼓励的四个方向

- 关注努力与过程，而非固定天赋。
- 关注进步与独特贡献，而非同伴比较。
- 让孩子自己评价成果和下一步。
- 在失败后保持连接，帮助孩子寻找可调整的策略。

### 特别时间

家长与孩子、教师与学生都可以安排短而稳定的专注时间。时间不必很长，但要提前说明、尽量不被手机或家务打断，结束时让孩子知道下一次何时到来。

### 训练与常规

鼓励不仅用于冲突后的安慰，也应嵌入日常任务：共同设计早晚常规、使用非语言信号、练习如何请求帮助、把大任务拆成小步。

## Key Concepts

- 具体描述比泛泛说“真棒”更容易让孩子看见自己的能力。
- 拥抱、眼神和靠近有时比更多语言有效，但必须尊重孩子是否愿意。
- 成人可以承认自己的失误并修复，这本身就是鼓励。
- “更好”比“完美”更适合长期学习。
- 社会压力、比较和过度奖励会削弱内部动机。

## Mental Models

### 从外部评价到自我评价

成人说什么 → 孩子注意过程 → 孩子表达自己的判断 → 孩子在没有成人时仍能继续。每次互动都可以把评价权逐步交回孩子。

### 水和植物模型

孩子需要持续的鼓励，就像植物需要水；偶尔在危机中集中赞美，不能替代日常关系与参与感。

## Anti-patterns

- 把鼓励变成“你是最聪明的”“你永远能做到”。
- 孩子失败时急着说“没关系”，跳过真实失落。
- 只有取得成绩才给关注。
- 用奖品、贴纸和排名取代共同设计的责任。

## Worked Example

孩子写字比昨天整齐。成人可以说：“我看到你把每一行的间距调整了，还擦掉重写了一处。你自己觉得哪一部分最满意？下次想继续保持什么？”这比“你真聪明”更能让孩子识别自己的策略。

## Key Takeaways

1. 鼓励培养自我评价和持续尝试。
2. 关注努力、策略、贡献与进步。
3. 把鼓励放入常规、特别时间和修复关系中。
