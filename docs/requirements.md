# parent-skills 需求文档

- **状态**:需求共识已达成,尚未实现。本文档是当前唯一交付物,只记录需求,不附带任何实现。
- **版本**:v1.0(2026-09-08,to-teacher 体系)→ v1.1(2026-09-08,加入 to-child)

## 1. 背景与目标

家长面对两个方向的沟通,都不对称:对老师,孩子在老师手里、家长缺少话术训练;对孩子,家长有权威但缺方法,情绪先行。本项目产出一套**可分发给其他家长**的 AI skills,在真实时刻给家长具体、敢用的支持。

"教家长沟通/教育"在 v1 收敛为四件事,分属两个对话式 skill:

- **对老师**:代笔(意图→消息)、接招(老师回复→分析+下一步)
- **对孩子**:解释(孩子的问题→符合年龄与家庭价值观的回答)、教练(状况→应对话术+长期策略)

## 2. 用户与前提

- 目标用户:中国家长,多数非技术背景
- **无个人预设**:skills 不硬编码任何特定家庭的信息;每个家庭的上下文由 `parent-setup` 现场收集
- 所有内容(SKILL.md 正文、触发描述、话术、README)使用中文;skill 目录名用英文 kebab-case(工具链兼容)

## 3. v1 范围:三个 skill

### 3.1 `parent-setup` —— 收集家庭上下文

通过一轮中文采访收集**静态事实**,默认只保留在当前对话中。

字段清单:

- **家长**:与老师沟通的主要负责人;希望 AI 使用的语气与自称(如"xx 爸爸/妈妈")
- **孩子**:年级与年龄;学校体制(公立/私立/国际);需要老师特别注意的点(如有)
- **老师**:沟通对象名单与角色(班主任/科任);主要沟通渠道(微信群@/私聊微信/电话/面谈)及各渠道的正式程度
- **家庭教育上下文**(v1.1 新增,服务 `to-child`):
  - 主要教养人及教育一致性(父母/祖辈是否同频)
  - 家庭教养理念与底线(默认正面管教;明确不可逾越的,如不打骂)
  - 孩子性格特质(如慢热/敏感/好动)与近期状态
  - 已有家庭规则(作业、屏幕、作息)

规则与边界:

- **落盘规则**:仅当用户明确说"保存"时,写入 `~/.parent-skills/profile.md`;否则不产生任何本地文件
- 不收集、不存储动态观察(老师风格、历史摩擦、话术效果)——那属于延后的 case log(§6)

### 3.2 `to-teacher` —— 对话式沟通助手(老师侧)

一个 skill 覆盖完整对话流,两种输入自然切换:

1. **家长意图 → 消息草稿**:家长用大白话说意图,或贴出自己写的草稿;skill 起草或改写,给出可直接发送的消息,必要时提供同一立场的软/硬两个版本供选择
2. **老师回复 → 分析 + 下一步**:家长贴老师的原话,skill 分析言外之意与立场,给出下一步消息建议

- 内置**严重度识别**(§4.1):自动判断场景处于合作档还是红线档,并向家长说明当前判断及理由
- 质量标准:输出的消息必须"家长真的敢发出去"——得体但不空转;敏感场景下不输出"感谢老师反馈"式的模板话术

### 3.3 `to-child` —— 对话式沟通助手(孩子侧,v1.1 新增)

**运行形态:家长代理**。skill 服务家长,由家长转述、执行;孩子不直接与 AI 对话(孩子直接用进 backlog §6)。

两种输入自然切换:

1. **解释模式**:"孩子问我 X" → 给出回答脚本。区分两类:
   - 知识类(天为什么是蓝的):按年龄段给出能听懂的答案
   - 棘手类(死亡、性、公平、"老师为什么抓我"):遵循四原则——**先问后答**(先了解孩子已经知道什么、怎么想)、**不撒谎**、**按年龄分层给真相**(不一刀切"长大就懂了")、**允许"我们一起查"**
2. **教练模式**:两种输入 → 育儿教练,默认立场为正面管教(§4.2):
   - 状况式:"孩子做了 X / 出了 X 状况,怎么处理"→ 分析行为背后的需求,给当下应对话术 + 长期策略
   - 求学式:"怎么立规矩 / 怎么培养习惯"→ 给方法论讲解,落到本家孩子的具体做法

通用机制:

- **年龄适配**:references 按年龄段组织,年龄读自 profile;v1 只把 5-9 岁写深,其他年龄段留骨架(§6 后补)
- **转介红线**(§4.2):三条信号出现即停止话术 coaching,转建议专业评估
- 质量标准:话术要"家长说得出口、孩子听得进去"——不输出居高临下的说教模板

## 4. 立场(所有话术由此推导)

### 4.1 `to-teacher` 沟通立场

| 档位 | 触发 | 策略 |
|---|---|---|
| **合作档(默认)** | 日常沟通:作业、成绩、课堂纪律、请假等 | 关系优先:私聊、给台阶、先核实后表态;默认老师善意,措辞不指责 |
| **红线档(自动切换)** | 人身伤害、羞辱性对待、歧视 | 取证(照片/书面记录)→ 书面沟通留痕 → 按升级阶梯推进:科任老师 → 班主任 → 年级组长 → 校长 → 教育局 |

- 切换由 `to-teacher` 自动识别并**明确告知**家长"这属于红线情形,策略已切换"及理由
- 红线档不是立刻对抗,而是**留痕 + 明确立场**;升级是阶梯式、可回退的
- 两档共同约束:孩子后续仍在老师手里,强硬但不撕破

### 4.2 `to-child` 教育立场

- **默认立场:正面管教/尊重式**——和善而坚定,先联结后纠正;规则清晰,执行一致;不体罚、不羞辱。与 `to-teacher` 合作档同源。使用中可按家庭理念调整(profile 中记录)
- **转介红线**(skill 自动识别并明确说明观察依据):
  1. 疑似创伤迹象:持续噩梦、睡眠倒退、退缩、拒绝上学等
  2. 疑似虐待(任何人,含校内校外)
  3. 疑似发育问题:与同龄人显著持续的差异
  - 触发后:停止给话术,建议儿童心理咨询/专业评估,并提供观察记录建议(何时开始、频率、具体表现)
- 边界:不替代专业诊断;不输出体罚、羞辱式建议

### 4.3 跨 skill 转介

同一事件常需两侧接力(转介是建议,不自动执行):

- `to-teacher` 处理中发现孩子侧需求(如"怎么跟孩子谈这件事")→ 提示可转 `to-child`,并交出事件摘要
- `to-child` 处理中发现涉老师的红线情形(如孩子透露被体罚)→ 提示可转 `to-teacher`(取证/留痕/升级阶梯)

## 5. 验收标准

1. `parent-setup` 一轮采访收齐 §3.1 全部字段(含家庭教育上下文),信息留在对话中;全程无本地写入,除非用户明确说"保存"
2. `to-teacher` 通过 §5.1 案例测试:产出的消息符合"敢发出去"标准,且能接住老师的防御性回复继续给出下一步
3. `to-child` 通过 §5.2 案例测试:解释模式给出符合年龄的回答脚本,教练模式给出"说得出口、听得进去"的应对
4. §6 延后功能全部记录在案、不在 v1 实现

### 5.1 验收案例一:酸奶事件·老师侧(真实案例,已处理完毕)

> 一年级男孩上课喝酸奶,老师抓住他的手、留下勒痕。孩子回家后家长发现。需要与老师沟通此事。

合格的 `to-teacher` 在此案例上应:

- 识别为红线情形(人身伤害边缘),切红线档并说明理由
- 第一步消息不质问:以了解情况开场,但立场明确;同时建议家长当晚拍照留证(家长手里只有孩子单方陈述,核实是第一步的目标之一)
- 预判老师的防御性回复(如"我没用力/孩子乱动"),给出不升级但坚持立场的应对
- 全程把"孩子后续在老师手里"作为措辞约束

### 5.2 验收案例二:酸奶事件·孩子侧(与案例一首尾呼应)

同一事件,`to-child` 教练模式。合格的 `to-child` 应:

- 给出**不诱导的核实提问**脚本:开放式("然后呢?""老师的手是怎么放到你手上的?"),而非引导式("老师是不是抓得很疼?")
- **两件事分开讲**:"上课喝酸奶违反课堂规则,规则还是要遵守" ≠ "老师抓手把你抓疼,这是大人处理得不对,不是你该受的"
- **安全感优先**:明确告诉孩子"告诉爸爸妈妈是对的";不在孩子面前妖魔化老师(孩子还得在那间教室坐下去)
- 给出后续观察指引:接下来几天看什么(睡眠、是否抗拒上学、提及老师的频率)、什么信号触发 §4.2 转介红线

## 6. 延后功能(backlog,按优先级)

1. **复盘模式 + 方法论滚雪球**:沟通结束后分析全程、沉淀结构化 case log(仅存本地);定期把 case 提炼回 repo 的话术原则库(distill),分发的方法论随版本演进
2. **备会模式**:家长会/单独约谈前的问题清单、听取要点、提异议的方式
3. **演练模式**:AI 扮演老师(可设定严厉/敷衍/防御风格),发消息前先过招
4. **一键安装脚本**:面向非技术家长(v1 为手动 clone + symlink)
5. **动态观察存储**:老师风格、历史摩擦、话术效果(依赖 case log 先行)
6. **孩子直接用 AI**(儿童端对话):屏幕时间、内容安全、防依赖是独立的产品问题
7. **其他年龄段深度内容**:10-12(青春期前)、13+(青春期),v1 仅有骨架
8. **系统性育儿课程**:分主题的主动学习(非状况驱动),如"正面管教二十讲"
