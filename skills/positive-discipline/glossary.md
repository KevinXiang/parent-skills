# 术语表

**3R1H** — 解决问题的判断标准：相关、尊重、合理、有帮助（Ch 6）。

**“赢得”孩子** — 以尊严、和善、坚定和鼓励取得孩子心甘情愿的合作，而不是用权力“赢了”孩子（Ch 2）。

**“积极的暂停”** — 事先共同设计的恢复空间或时间，帮助人感觉好起来、重新接通理性大脑，再处理问题；不是惩罚性隔离（Ch 6）。

**归属感和价值感** — 书中认为行为的首要社会目标；缺失时，孩子可能用错误方式寻求连接（Ch 2, Ch 4）。

**鼓励** — 帮助孩子形成“我能行、我能贡献、我能影响”的能力感和社会技能（Ch 7）。

**家庭会议** — 每周一次、全家参与的倾听、致谢、计划和解决问题的结构化会议（Ch 9）。

**和善而坚定** — 同时尊重孩子、自己和情形需要；既不严厉控制，也不娇纵（Ch 1）。

**逻辑后果四个 R** — 相关、尊重、合理、预先告知；缺少任何一个，都可能变成惩罚（Ch 5）。

**目的揭示法** — 在平静、客观、友善时，用“会不会是……”猜测行为背后的错误目的，让孩子确认或修正（Ch 4）。

**社会责任感/集体感** — 真心关心同伴并愿意为家庭、班级或社会作贡献（Ch 2）。

**生活态度取向** — 儿童时期形成的、在压力或不安全时寻找归属感和价值感的行为蓝图；包括安逸、控制、取悦、力争优秀（Ch 10）。

**特别时光** — 预先安排的、短而专注的亲子或师生一对一时间，用于连接和鼓励，不以纠正问题为主题（Ch 7）。

**退缩（Retreat）** — 惩罚造成的四个 R 之一：偷偷摸摸地躲避被抓，或因自卑而放弃努力（Ch 1, Ch 5）。

**自然后果** — 没有成人干预而自然发生的结果；成人可以同情和支持，但不借题发挥或包揽困难（Ch 5）。

**矫正错误的三个 R** — 承认（Recognize）、和好/道歉（Reconcile）、解决（Resolve），用于把错误转为学习和修复关系的机会（Ch 2）。

**四种错误目的** — 过度关注、寻求权力、报复、自暴自弃；都是以错误信念追求归属感和价值感（Ch 4）。

**惩罚造成的四个 R** — 愤恨（Resentment）、报复（Revenge）、反叛（Rebellion）、退缩（Retreat）（Ch 1）。

**赢得合作的四个步骤** — 理解感受、表达同情、分享自己的感受、共同解决问题（Ch 2）。

**班会** — 以圆圈、致谢、议程、倾听、头脑风暴和非惩罚性解决方案为核心的班级民主练习（Ch 8）。

**正面管教** — 以相互尊重、合作、和善而坚定、内在自律和长期人生技能为目标的管教方式（Ch 1）。

**自暴自弃** — 错误目的之一：孩子相信自己不可能有所归属或完成任务，于是放弃尝试；需要分步骤训练和小成功（Ch 4）。

**自我评价** — 引导孩子识别自己做得好的地方、需要改进的地方和下一步，而不是依赖外界赞扬判断价值（Ch 2, Ch 7）。

**“特权 = 责任”** — 享有玩具、活动等特权与照料、合作等责任相伴；缺乏责任可能导致暂时失去相应特权（Ch 5）。

**“你一……我们就……”** — 描述条件与成人将采取的行动，给孩子明确选择空间；不能说了却无法接受孩子不选择（Ch 11）。
