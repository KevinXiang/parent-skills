# 决策速查表

## 先判断：现在该控制，还是该交还？

| 情形 | 默认行动 | 原因 |
|---|---|---|
| 即时安全、严重伤害、违法或侵犯他人权利 | 成人清楚介入，并解释原因 | 安全边界不可外包 |
| 可修复、低风险的日常后果 | 交还问题，提供顾问式支持 | 让孩子练习判断与责任 |
| 孩子情绪高涨 | 先共情和共调节，暂缓方案 | 大脑未平静时难以学习 |
| 成人自己很焦虑/愤怒 | 先暂停、找成人支持、延后谈话 | 不让孩子管理成人情绪 |

## N.U.T.S. 快速诊断

- 若是**新奇**：预演、拆步骤、提供熟悉样本。
- 若是**不可预测**：提前告知、写清流程和检查点。
- 若是**自我威胁**：去比较化，讨论策略而非人格。
- 若是**低控制感**：交还一项真实的路径、顺序或求助选择。

## 说法替换

| 少用 | 改用 |
|---|---|
| “你必须马上做。” | “这件事需要处理；你想先自己定办法，还是一起想？” |
| “你怎么这么懒？” | “开始这件事最难的部分是什么？” |
| “我早就说过。” | “这次给了你什么信息？下次想怎么试？” |
| “快道歉。” | “你觉得发生了什么影响？怎样修复会比较合适？” |
| “别紧张。” | “这件事看起来很有压力；哪一部分最不可控？” |

## 睡眠/设备规则是否健康？

- 孩子能说出规则保护的是什么，而不只感到被监控。
- 有时间、地点与睡眠边界，也有协商和复盘的机制。
- 规则没有挤压亲子关系；必要时成人愿意先调整自己的设备习惯。

## 警讯

- 持续显著影响睡眠、上学、关系或日常功能：考虑合格专业评估。
- 自伤、他伤、无法保证即时安全：优先联系当地紧急服务或危机支持，不以家庭对话替代。
