# 现场速查

## 先判断，再开口

| 看到的情形 | 先做什么 | 接着怎么说 |
|---|---|---|
| 伴侣开口带刺（苛刻开场） | 不接刺，暂停片刻温和重启 | “先停一下，我重新说这件事。” |
| 自己想说“你总是／从来不” | 换成抱怨三要素 | “这周三天都是我盯作业，我挺累也委屈；能固定你管周二周四吗？” |
| 心跳加快、想吼或想逃 | 立即暂停至少20分钟 | “我被情绪淹没了，休息20分钟再谈。” |
| 对方递来示好或认错 | 先接住，再谈分歧 | “嗯，你是先讲了三遍。” |
| 伴侣倾诉工作／带娃压力 | 只倾听不建议，一致对外 | “太不公平了！后来呢？” |
| 伴侣语气冲地提请求 | 回应信息不回应语气 | “你想让我现在收拾桌子，对吧。” |
| 同一冲突反复无解、妥协像背叛 | 改谈梦想，不谈解决 | “讲讲这件事对你意味着什么？和你的童年有关吗？” |
| 姻亲拉扯、伴侣与父母起冲突 | 站在伴侣一边，不当和事佬 | “这是我和她的家，规矩我们来定。” |
| 感觉两人疏远了 | 用傻瓜探测器自查，超过4条3天内温和开谈 | “嘿，我觉得跟你失去了联结，我们怎么了？” |

## 末日四骑士速查

| 骑士 | 表现 | 解药 |
|---|---|---|
| 批评 | “你从来不管孩子”（人格否定） | 抱怨三要素：具体行为＋感受＋需求 |
| 蔑视（最致命） | 讥笑、翻白眼、挖苦、道德贬低 | 尽早抱怨不积怨；日常喜爱与赞美 |
| 辩护（防御） | “这不是我的问题，是你的问题” | 先承认对方话中属实的部分 |
| 筑墙（冷战） | 沉默、回避、面无表情 | 读作自我保护，暂停后主动回来 |

四骑士是“值得警惕的模式”，不是判决；发现自己出现时，改的是模式，不是给自己贴标签。

## 冲突分诊

| 问题 | 可解决的冲突 | 永恒的冲突（占69%） |
|---|---|---|
| 指向 | 具体情境（这周谁接娃） | 根本差异（管教价值观） |
| 谈起来 | 围绕具体事务 | 一谈就上升到信任、自私、价值观 |
| 走向 | 可谈判、可妥协 | 反复出现、立场越来越极端 |
| 策略 | 法则5五步法（温和开场、修复、暂停、妥协、抚平创伤） | 法则6梦想对话，与问题共存 |

自查：觉得被拒绝、谈完更受伤、没有幽默感、观点极端化、各过各的——命中多条即已滑向僵局，按永恒冲突处理。

## 每周维护（神奇的6小时）

- **分开时**：出门前了解伴侣当天的一件事（2分钟/天）。
- **回到家**：拥抱亲吻至少6秒；20分钟减压对话。
- **赞美与亲昵**：每天各5分钟，具体的“我爱你”与拥抱。
- **约会**：每周2小时，用开放式问题更新爱情地图。
- **关系会谈**：每周1小时——好事开场→各5条欣赏→温和谈冲突→互问“下周我能做什么让你感到被爱？”

## 常见翻译

| 自动反应 | 转向 |
|---|---|
| “我同意，不过……” | “我同意，还有吗？咱们再商量怎么安排。” |
| “你让我很丢脸／你真自私。” | “刚才的事让我又急又委屈，因为我需要咱俩一条战线。” |
| “这有什么好怕的。” | “是什么让你这么担心？我想听听。” |
| “你别哭了，我去处理。” | “你很难过，先说给我听，我们一起看怎么办。” |
