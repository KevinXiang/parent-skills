# 术语表

**爱情地图**——大脑中存储伴侣生活信息的“地图”：日常琐事、喜恶、压力与人生目标；需终生更新（Ch 4）。

**抱怨三要素**——具体行为＋我的感受＋我的需求；批评的解药（Ch 3）。

**夫妻友谊**——幸福婚姻的地基：相互了解、尊重、喜爱并享受陪伴（Ch 2）。

**夫妻信任标尺**——反映夫妻彼此信任度的指标，出自《爱的博弈》（Ch 2）。

**抚平情绪创伤**——冲突平息后专门处理争吵留下的伤害：轮流谈感受、需要、触发点并道歉（Ch 9）。

**感情修复尝试**——任何防止消极情绪失控的言行：玩笑、暂停、道歉；成败取决于友谊质量（Ch 2, Ch 3, Ch 9）。

**高期望原则**——对婚姻期望最高的夫妻婚姻质量常常最高；降低期望换不来太平（Ch 13）。

**沟通尝试**——伴侣对关注、感情、幽默或支持的微小请求；回应它即“转向”（Ch 6）。

**共鸣联结**——夫妻在核心情感层面被对方理解的体验（Ch 2）。

**共同意义的4大支柱**——联结仪式、对彼此角色的支持、共同的目标、共同的价值观和信仰（Ch 12）。

**婚姻傻瓜探测器**——每段婚姻内置的预警系统；每周对照问题清单自查，超过4条即3天内温和开谈（Ch 13）。

**婚姻情商**——在日常生活中让对彼此的积极想法与情绪不被消极情绪压倒的能力，可以学习（Ch 1）。

**婚姻情感任务**——金钱、家务、育儿等每个常见冲突主题背后对应的任务；冲突源于两人对任务的看法不同（Ch 10）。

**积极情感主导**——友谊牢固后关系被“设定”为积极状态，中性话语不易被听成攻击（Ch 2, Ch 6）。

**减压对话**——每天各15分钟轮流诉说一天，只倾听不建议，唯一禁区是婚姻冲突本身（Ch 6, Ch 13）。

**僵局**——永恒冲突处理失败后的危险状态：反复无解、日益极端、妥协像背叛；信号是背后藏着未被尊重的梦想（Ch 8, Ch 11）。

**健康关系之屋**——7大法则构成的结构，信任与承诺是承重墙；用于排查婚姻薄弱环节（Ch 2）。

**接受伴侣影响**——尊重伴侣的意见和感受，分享权力，共同做决定（Ch 7）。

**苛刻的开场白**——以批评或讥讽开启谈话；前3分钟几乎决定整场走向（Ch 3）。

**梦想**——立场背后的深层希望与渴望，是身份的一部分，多与童年有关（Ch 11）。

**梦想捕手**——倾听者引导伴侣揭示梦想的问题，如“你的立场对你意味着什么？”（Ch 11）。

**末日四骑士**——批评、蔑视、辩护（防御）、筑墙（冷战）四类消极对话模式；蔑视最致命（Ch 3）。

**情感银行账户**——每次转向彼此都是一笔储蓄，在压力与冲突时充当缓冲（Ch 6）。

**情绪淹没**——心率超100次/分、触发“战斗或逃跑”的状态；此时生理上无法倾听，必须暂停（Ch 3, Ch 9）。

**神奇的6小时**——每周约6小时的日常小练习：分开时问询、6秒拥抱、减压对话、赞美、亲昵、约会、关系会谈（Ch 13）。

**微文化**——夫妻自创的习俗、仪式与故事构成的象征体系（Ch 12）。

**温和的开场白**——承认自己的部分责任＋以“我”开头说感受＋只描述事实＋明确说出积极需要（Ch 9）。

**“我们”意识**——夫妻作为共同体的身份感；姻亲与育儿冲突的核心任务都是建立并扩展它（Ch 10）。

**喜爱与赞美系统**——认为伴侣值得尊重、敬佩的基本感觉；蔑视的解药（Ch 5）。

**消极情感主导**——把中性话语听成人身攻击的状态；长期会陷入“伴侣捕鼠器”式零和认知（Ch 2）。

**永恒的冲突**——源于性格、价值观根本差异的冲突，占69%；不求解决，只求管理（Ch 8, Ch 11）。

**可解决的冲突**——聚焦具体情境、可通过谈判与妥协解决的冲突，按法则5处理（Ch 8, Ch 9）。

**糟糕的回忆**——负面情绪改写过去，善意被解读为别有用心；关系需要干预的警讯（Ch 3）。
