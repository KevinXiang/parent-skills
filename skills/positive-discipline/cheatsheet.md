# 正面管教速查

## 先判断，再行动

| 如果你看到/感觉到 | 先问自己 | 优先尝试 |
|---|---|---|
| 孩子反复打断、纠缠；你很烦 | 他是在求建设性关注吗？ | 特别时光、任务、无言信号；不提供特别服侍 |
| 孩子顶嘴、对抗；你感到被挑战 | 我们是否在争谁说了算？ | 退出权力之争；“我不能强迫你，我们一起找办法” |
| 孩子说伤人的话、破坏东西；你很受伤 | 他是否先感到受伤？ | 不还击；冷静、倾听、连接，再弥补/解决 |
| 孩子说“我不会”并想让你走开 | 他是真的不会还是在求关注？ | 拆成一步、示范、安排小成功；不要放弃 |

## 四个标准

行动前检查：

1. 和善 + 坚定？
2. 增加归属感/价值感？
3. 长期有效，而非只求马上安静？
4. 教会责任、合作、自律或解决问题？

任一项为“否”，先暂停并换工具。

## 后果选择

- 安全且孩子有能力理解 → 允许自然后果；同情，不说教，不解救。
- 必须成人介入 → 逐项检查“相关、尊重、合理、预先告知”。
- 后果不像在帮孩子、而像在让孩子吃苦头 → 放弃后果，改做 3R1H 解决问题。
- 享有特权却不承担相关责任 → 清晰预先说明；执行暂时失去特权，不附加羞辱或报复。

## 冲突脚本骨架

“我看得出你很___，我理解你为什么会这样想。我的感受是___，因为___。等我们都好受些，你愿意和我一起想一个对双方都有帮助的办法吗？”

情绪上头时：

“我们现在都听不进去。我先去积极暂停/让自己冷静，感觉好些后再回来。这个问题不会被忽略。”

## 解决问题提问

“发生了什么？” → “你当时想完成什么？” → “你有什么感受？” → “你从中学到了什么？” → “下次怎么做会更有帮助？”

不要预设答案；不要在愤怒时追问“为什么”。

## 鼓励判断

- 想让孩子依赖你的评价 → 可能是赞扬。
- 想让孩子能自我评价、看见努力并继续改进 → 鼓励。
- 先说做得好的具体处，再问“你觉得哪里要改进？”
- 进步比完美重要；一次只练一个新方法。

## 会议默认值

- 班会：小学尽量每天或每周 3–5 次；圆圈、致谢、议程、轮流发言、头脑风暴、非惩罚方案。
- 家庭会议：每周一次；决定以全体同意为目标；最后安排下周活动并以共同娱乐结束。
- 议题写“问题”，不写“某某这个坏孩子”；当事人选最有帮助的方案。
