# 第12章：在家管理孩子——解决问题的艺术

## Core Idea

当既有规则无法应对新问题时，家庭需要从“当场争输赢”转向系统问题解决。原书提供七步流程，把含糊抱怨变成积极、具体、可试行的计划；同时通过过渡预告和“只有……才能……”的明确顺序，减少 ADHD 儿童在切换与等待中的负荷。

## Frameworks Introduced

### 问题解决七步法

1. 界定问题，先说事实。
2. 将问题行为改写为希望出现的积极行为。
3. 尽可能列出选项，暂不急着批评。
4. 评估每项选择的收益、成本和可行性。
5. 选出最优或最可先试行的方案。
6. 若照料者有分歧，听取理由并形成可执行妥协。
7. 执行一段时间，再根据数据复盘。

### 过渡支持

对活动开始、结束和地点转换，提前预告下一步、重述规则、给可见倒计时，并在顺利转场后立刻反馈。

### “只有……才能……”策略

把责任与后续活动清楚串联，例如“只有完成洗漱，才能开始故事时间”。它应是预先说明的生活顺序，不是临时羞辱或不可能完成的交易。

## Key Concepts

- **积极重述**：从“不要拖延”转成“在约定时间启动第一步”。
- **试行期**：新计划需要足够时间才能判断；同时应有复盘点，避免无限期硬撑。
- **共同照料者协商**：成人先统一最低限度的行动，减少孩子面对相互矛盾规则。

## Anti-patterns

- 在双方愤怒时召开“问题解决会议”。
- 把列选项变成成人已有答案的伪选择。
- 方案太抽象，例如“以后自觉一些”。
- 因孩子第一次反抗或遗忘就废弃整个计划。

## Worked Example

家庭因每天关电视大吵。把问题从“孩子沉迷”重述为“晚八点后能在五分钟内完成关机并转入洗漱”。可选项包括两次预告、孩子自己按计时器、关机后选一项短暂过渡活动。家庭先试行“十分钟和两分钟预告 + 孩子按计时器 + 成功后自己选故事”，三天后检查是否需要调整。

## Key Takeaways

1. 先把问题写成希望看见的具体行为。
2. 计划应有时间、地点、责任人和复盘点。
3. 预告、顺序和可见时间能显著降低过渡冲突。
