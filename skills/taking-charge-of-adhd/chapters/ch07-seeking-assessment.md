# 第7章：决定让孩子做 ADHD 评估

## Core Idea

专业评估不是给孩子贴标签，而是澄清困难、识别功能损害与共病、排除其他解释，并把支持资源连接起来。家长不必等到“完全失控”才求助；当问题长期存在、跨场景出现、损害学习/关系/安全，或家庭已用常规方法无法应对时，就值得咨询具备相关经验的专业人员。

## Frameworks Introduced

- **转介时机四问**：
  1. 困难是否持续而非短暂波动？
  2. 是否至少在一个重要生活领域造成损害，并可能跨场景出现？
  3. 是否存在安全、学校、情绪、同伴或家庭危机？
  4. 家庭和学校已有支持是否仍不够？
- **找对专业人员**：询问其是否熟悉儿童 ADHD、全面评估、共病/学习问题、行为与学校支持，以及如何同家庭和学校沟通。
- **带着问题去评估**：评估目标不仅是“有没有 ADHD”，还包括“哪些功能最受影响、还要排除什么、下一步谁负责什么”。

## Key Concepts

- **转介**：为获得更专业的评估或治疗意见而进入服务系统。
- **信息来源**：家长、教师、孩子本人、病史和学校材料各有价值，不能互相替代。
- **差异诊断**：专业人员需考虑睡眠、学习、焦虑、情绪、创伤、健康和其他发展问题。

## Anti-patterns

- 等到学校处分、关系破裂或安全事件才行动。
- 只问“能不能开证明/开药”，没有明确功能问题。
- 仅凭社交媒体、线上自测或熟人描述确诊。
- 选择服务时只看是否给出想听的答案，不问评估方法和随访安排。

## Worked Example

家长准备初诊时，把“孩子很不听话”改成三条事实：过去六个月在家完成晚间常规平均需要 90 分钟；课堂作业常未完成；因冲动与同学起冲突。再列出睡眠、视力、学习、既往发展和家庭史信息。这样专业人员能更快判断是否需要跨场景材料、医学检查或学习评估。

## Key Takeaways

1. 评估服务于理解和支持，不是身份判决。
2. 用具体的功能损害、时间和场景描述问题。
3. 合格评估应考虑其他可能解释和共同困难。
