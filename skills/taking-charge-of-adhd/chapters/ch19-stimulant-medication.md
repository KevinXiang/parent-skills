# 第19章：经批准的兴奋剂类药物

## Core Idea

本章介绍兴奋剂类药物在 ADHD 治疗中的证据、常见误解、可能副作用和临床监测问题。对家长而言，最可迁移的技能不是记住药名或自行比较剂量，而是与具备儿童 ADHD 经验的开方医生共同界定目标、核对健康与用药信息、观察实际效果，并在出现问题时及时联系专业人员。

## Frameworks Introduced

- **共同决策循环**：明确要改善的功能目标 → 获得个体化医学评估 → 了解预期获益与风险 → 记录家庭/学校观察 → 按约随访并由医生决定调整。
- **辨别“药物不是魔法”**：在临床管理下，药物可能改善部分核心症状和表现条件；它不会自动教会知识、社交技巧、组织能力或修复家庭关系，因此仍需教育和行为支持。
- **医生提问框架**：询问目标、预期效果、常见和严重不良反应、病史/相互作用、监测方式、随访频率、错服或紧急情况的处理渠道。

## Key Concepts

- **基线**：开始任何临床干预前对目标问题的可观察记录，便于判断实际变化。
- **副作用监测**：由医生说明需要关注的变化，并结合孩子的既往健康情况判断。
- **知情同意**：理解可选方案、已知利益/风险和替代方案后参与决定。
- **处方管理**：药物保管、服用和任何变更均应遵守当地法律与开方医嘱。

## Anti-patterns

- 依据其他家庭经验、短视频或本章摘要自行开始、停用、加减药。
- 因单日好坏就断定药物“完全有效/无效”。
- 把药物视为唯一干预，取消学校、行为、睡眠和家庭支持。
- 隐瞒其他药物、补充剂、既往反应或健康问题。

## Worked Example

就诊前，家长带去两周记录：早晨启动、课堂任务完成、晚间冲突、睡眠与食欲的变化；另列出所有处方药、非处方药和补充剂。家长请医生说明本次尝试要改善哪两个目标、何时评估、哪些变化需要尽快联系医院。之后仅按医生要求监测和回访，不在家庭中自行改变方案。

## Key Takeaways

1. 药物讨论必须以个体化医学评估和随访为中心。
2. 观察功能目标和不良反应，比追逐笼统标签更有用。
3. 药物、行为和学校支持通常解决不同层面的问题。
