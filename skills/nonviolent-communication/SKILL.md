# 非暴力沟通（修订版）

**作者**：马歇尔·卢森堡 | **章节**：14 章 | **生成**：2026-09-22

## 如何使用

- 没有指定主题时，先用下方四要素梳理当下的互动；必要时先暂停，避免把这套语言当成要求对方顺从的技巧。
- 给出具体情境时，先确认安全和权力差异，再区分事实、感受、需要与可协商的行动；按主题索引读取相应章节。
- 需要可直接说出口的话术时，优先读 [patterns.md](patterns.md)；需要现场判断先读 [cheatsheet.md](cheatsheet.md)。
- 这套方法服务家长，输出应由家长转述和实践，而不是让孩子独自承担关系修复。

非暴力沟通不等于永远温和、同意对方或取消边界。成人仍须在孩子有即时危险、伤害他人、破坏物品或需要执行既定保护措施时坚定介入。若出现疑似虐待、持续创伤反应、自伤/他伤风险或其他紧急安全问题，先保障安全并寻求合适的专业或紧急支持；不要用沟通练习延误处置。

## 核心框架与思维模型

### 1. 目标是连结和由衷给予，不是赢得配合

非暴力沟通把注意力从“谁对、谁错、谁该被纠正”转向“此刻各自发生了什么、在乎什么、能否找到照顾双方需要的行动”。它不保证对方马上改变，也不是把四个步骤包装成更精致的命令。尤其家长处在权力较强的位置时，要让孩子能说“不”、能表达不同感受，并把安全所必需的界限讲清楚。

### 2. 四要素：观察、感受、需要、请求

按这一顺序组织自己的表达：

1. **观察**：说出可被录像或复述的具体行为与情境，不掺“故意、总是、懒、没礼貌”等判断。例如“晚上八点后，你两次还在平板上看视频”。
2. **感受**：说自己的情绪和身体体验，如担心、失望、疲惫、害怕、轻松；“我觉得你不尊重我”通常是对他人的判断，不是感受。
3. **需要**：说明感受关联的普遍价值或需要，如休息、安全、合作、尊重、自主、被理解、秩序或玩耍。不要把某一种解决方案伪装成需要。
4. **请求**：提出对方此刻能观察到、能选择、可讨论的正向行动，并允许对方拒绝或协商。如“你愿意在八点十分前把平板交到客厅充电吗？”

可用骨架是：“当我看到/听到……，我感到……，因为我需要……。你愿意……吗？”语序不是重点；持续对自己和对方的四要素保持觉察才是。

### 3. 用“需要”替代归咎

他人的言行会触发我们的感受，却不是感受的唯一原因。说“你让我生气”容易让对方听见责备；说“我生气，因为我需要可靠的协作”把责任带回自己，也让对方知道可以如何理解你。反过来，孩子的抱怨、顶撞、哭闹或拒绝，也先尝试听作未被满足的需要，而非人格缺陷。猜测需要时用询问而不是宣判：“你是不是很失望，因为还想继续玩？”

### 4. 同理不是同意，而是先确认生命经验

同理心是把注意力放在对方的观察、感受、需要和请求上。不要急着解释、纠正、建议、比较、安慰或讲自己的故事。可先简短复述并留出停顿：“你很委屈，因为你希望我先听你说完，是吗？”对方被充分听见后，才更可能有余裕听你的界限、影响和请求。

### 5. 请求必须可拒绝；边界仍须可执行

如果孩子不答应就会受惩罚、被羞辱或被剥夺关系，语言再客气也更像要求。先同理“不”的需要，探索替代方案。若事情涉及安全或成人职责，则诚实说明这不是可选项：例如“我听见你还想玩。现在我要收起平板，因为睡眠和明早上学需要被保护；你可以选自己关机，或我来帮你关。”不要假装这是一项自由请求。

### 6. 愤怒是需要未被看见的警报

愤怒提示我们正在依赖“他不该这样”“她应该懂”的评判。先停下可能伤人的表达，转向：我在指责什么？我真正害怕、珍视或需要什么？然后用四要素表达。理解愤怒不等于允许吼叫、羞辱或伤害；需要先保护人，再回到连结和修复。

### 7. 自我同理让选择从自动反应中出现

当你后悔吼了孩子、感到内疚或想控制局面时，先不自我惩罚。辨认自己当时想满足什么需要，以及现在最需要什么；再决定如何修复、学习或寻求支持。目标不是做“完美家长”，而是以更符合价值的方式行动。

## 使用顺序

1. **看安全与权力**：有人会受伤吗？我是否正在用身份、资源或惩罚逼迫对方？先处理即时风险。
2. **暂停自我同理**：给感受命名，找出自己重视的需要，避免在高唤起时盘问或说教。
3. **同理对方**：尝试猜测其感受和需要，问对方是否准确；被纠正时接受修正。
4. **清楚表达**：用观察—感受—需要—请求说明自己；请求具体、正向、可执行。
5. **协商与修复**：听见“不”背后的需要，寻找替代办法；冲突后再复盘影响、补救与下一次的约定。

本技能只综合《非暴力沟通（修订版）》中的框架，不替代医疗、心理、法律或儿童保护判断。不要把它用作诱导孩子顺从、回避必要界限或要求受伤者立刻和解的手段；在家庭中，成人要承担安全、规则与修复的主要责任。
