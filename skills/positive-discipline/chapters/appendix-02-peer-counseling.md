# 附录2：同伴辅导

## Core Idea

当班级中有学生持续带头打断、起哄或破坏规则时，公开惩罚可能强化其权力和关注目的。同伴辅导把学生视为可以学习新技能的人，通过关系、现实检视和小步承诺，帮助其成为有建设性的领导者。

## Five-Step Practice

本附录借鉴现实治疗式的五步训练：

1. 先建立真实关系和信任。
2. 具体询问“你现在在做什么”。
3. 一起检视这种做法是否有用、是否带来想要的结果。
4. 制定一个可操作的改进计划。
5. 确认承诺、支持和复盘时间。

## Guardrails

辅导不是同伴审判、逼迫表态或秘密监控。成人要确保学生自愿参与、目标清楚、计划可执行；若涉及安全、霸凌或持续伤害，应由负责的成人和专业支持介入。

## Worked Example

学生总在小组活动中煽动同伴。辅导者不说“你真讨厌”，而问：“你现在做了什么？你想让同伴怎么反应？这种方式有用吗？”学生选择下一次担任计时员，并约定收到一个非语言信号就停下来。活动后一起复盘是否更接近他的目标。

## Key Takeaways

1. 先建立关系，再检视行为效果。
2. 计划必须具体到一个下一次可观察的动作。
3. 同伴辅导不能替代成人对安全和伤害的责任。
