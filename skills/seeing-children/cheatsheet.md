# 现场速查

| 看到的情形 | 先判断 | 当下优先回应 | 之后再做 |
|---|---|---|---|
| 孩子崩溃、哭闹 | 是否安全；大人是否也被触发 | 少说、慢下来：“这很难，我在这里。” | 平静后命名感受，练习下次办法 |
| 打人、咬人、扔物 | 是否有人或物会受伤 | 身体阻止：“我不会让你伤人。”陪在安全处 | 修复影响，提供可接受的宣泄方式 |
| 顶嘴、无礼 | 是真实危险，还是失望的外壳 | 不上钩；边界加感受：“不能这样说话。你很失望。” | 连接后再谈尊重和替代说法 |
| 不合作、磨蹭 | 连接储备是否不足；要求是否突兀 | 先靠近、用游戏或选择启动 | 在平静时预告转场，补充情感资本 |
| 手足争吵 | 是否需要安全隔开 | 降温，不立刻判谁对谁错 | 分别连接；再帮助各自说需要 |
| 说谎 | 这个说法想保护或实现什么 | 回应愿望和困难，不先审问 | 保持真话边界，共同找可接受的办法 |
| 害怕、焦虑、害羞 | 是孩子的痛苦还是成人的不适 | “我相信你。等你准备好。” | 预演、渐进接触、编口头禅 |
| 分离或睡前黏人 | 成人焦虑是否混入；是否可预测 | 稳定告别和重逢承诺，不偷走 | 固定仪式，日间小分离练习 |
| 父母吼叫后内疚 | 是否把自责变成了孩子的负担 | 先自我调节 | 具体道歉、修复、准备替代反应 |

## 四句默认语言

- “你很想要这个；同时我会守住这个界限。”
- “我不会让你伤人/伤害自己/破坏东西。我会陪你度过这会儿。”
- “我想知道，这对你来说是什么感觉。”
- “刚才我处理得不好。那不是你的责任；下次我会先停下来再说。”

## 快速分流

1. 有即时危险 → 先阻止与求助。
2. 无即时危险但情绪很高 → 先共同调节，不讲道理。
3. 情绪下降 → 连接并好奇地解码需要。
4. 已能思考 → 共同复盘、修复、预演。

## 常见误判

- 孩子不立刻平静，不代表边界无效；先看是否保持安全和关系。
- 接纳感受，不代表同意行为。
- 自信不等于立刻参与；也可以是知道自己尚未准备好。
- 成人的不适是信息，不是要求孩子立刻改变的命令。
