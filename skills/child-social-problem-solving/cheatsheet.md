# ICPS 速查卡

## 先判断状态

| 看到的情况 | 先做什么 | 之后怎么问 |
|---|---|---|
| 有人正受伤、危险或攻击升级 | 平静阻止、分开、保护 | 都冷静后再还原问题 |
| 孩子或成人气到无法听 | 命名情绪、暂停、安抚 | “等我们能想办法时再谈” |
| 一般冲突、争抢、抱怨 | 不急着裁判 | 从“发生了什么？”开始 |
| 孩子已会 ICPS | 少问、留空间 | 一句“你能想个不同的办法吗？” |

## 四步提问

1. **问题**：发生了什么？你想要什么？
2. **感受**：你怎么样？他可能怎么样？我们怎么知道？
3. **办法**：这是一种办法；还能想一个不同的吗？
4. **后果**：如果这样，会发生什么？这真能解决吗？

## 常见分支

- 孩子只给一个办法 → “那是一种办法。这个游戏要找很多不同的办法。”
- 孩子重复同一种办法 → “这和刚才都是请大人帮忙；还有别的类别吗？”
- 孩子给出攻击性办法 → “如果这样，别人可能怎样？接下来呢？你能想个避免那个结果的办法吗？”
- 孩子把猜测当事实 → “也许；我们怎样能知道？看、听，还是问？”
- 第一个温和办法失败 → “它没解决；你本来就可以再想一种不同的办法。”

## 成年人的替换句

| 惯性说法 | ICPS 替换句 |
|---|---|
| “别抢，去分享。” | “你想把它拿回来；你们怎么才能都不生气？” |
| “你把他弄哭了。” | “你那样做后，他可能有什么感觉？发生了什么？” |
| “现在马上收拾。” | “玩具放这里会怎样？你能想个更合适的地方吗？” |
| “别烦我。” | “现在是合适的时间吗？等我忙完前你能做什么？” |

## 每周自检

若本周自己主要在命令、建议、解释，就选一个低压力时段练一段四步对话。成功的信号不是孩子次次顺从，而是孩子开始提出自己的问题、感受、办法和后果。
