# 快速决策

| 情境 | 先判断 | 优先动作 | 不要做 |
|---|---|---|---|
| 想为学习或工作提神 | 是否睡眠严重不足、脱水、生病或受伤 | 短暂、熟悉、可恢复的轻到中等活动后进入任务 | 以高强度训练硬压疲劳 |
| 压力长期高、身体紧绷 | 是否已影响睡眠、工作、关系或出现惊恐 | 降低门槛，安排规律活动、恢复和支持 | 把加量训练当作唯一解法 |
| 焦虑或恐慌 | 是否有胸痛、晕厥、急性风险或严重功能受损 | 在专业照护下，把安全活动作为辅助；必要时找人同行 | 擅自停药、故意用剧烈运动诱发症状 |
| 情绪低落 | 是否有自伤/自杀想法、极端激越或无法维持日常 | 尽快联系专业人员；若安全，做最小可完成活动 | 将“缺乏锻炼”归咎为个人失败 |
| 注意力困难 | 是否已确诊、正在用药或伴睡眠/学习问题 | 用规律活动支持作息和任务启动，并保留完整评估 | 把活动当作 ADHD 的替代诊断或治疗 |
| 减少成瘾行为 | 是否可能酒精/药物戒断或存在立即风险 | 联系成瘾治疗支持；用活动填补低风险时段 | 单独依靠运动戒断或突然停用物质/药物 |
| 孕期、产后、更年期 | 是否有并发症、盆底/骨骼问题、出血或严重情绪症状 | 先询问产科或相关临床团队，再选择适宜活动 | 套用书中旧建议或高风险项目 |
| 高龄或慢病起步 | 是否有新发胸痛、晕厥、重大平衡风险 | 以医疗允许范围内的渐进、可监督活动开始 | 用年龄公式自行设定高强度心率目标 |

## 两个工作模式

1. **状态模式**：一次短活动 → 恢复 → 观察清醒、焦虑、情绪或任务启动是否变化。  
2. **习惯模式**：选择可重复活动 → 逐步增加 → 每周复盘功能、愉悦、睡眠与疼痛 → 按需要调整。

## 书中观点的安全翻译

- “运动影响大脑” → 运动可能支持多项健康与心理功能，效果因人、剂量、情境和疾病而异。
- “像药物一样有效” → 某些研究比较过特定人群和特定方案；不能据此替代当前医疗决策。
- “坚持就对了” → 持续性重要，但应同时遵守安全、恢复和个体化限制。
