# ADHD 家长支持速查

## 先判断是哪一类问题

| 看到的情况 | 先做什么 | 不要先做什么 |
| --- | --- | --- |
| 长期跨场景困难且有明显功能损害 | 记录家庭/学校例子，安排合格专业评估 | 依据网络测试或单次量表自行诊断 |
| 知道规则但总做不到 | 在表现发生点增加提示、计时和即时反馈 | 反复提醒、长篇说教、归因为故意 |
| 新行为计划失效 | 检查目标是否少、具体、即时、可执行 | 一次添加许多规则或加重惩罚 |
| 学校持续困难 | 与教师共定 2–3 个可观察目标并追踪 | 要求教师只靠“更严格”解决 |
| 诊断后情绪崩溃 | 承认失落/愤怒，寻求可靠信息与支持 | 用羞耻、否认或恐慌驱动决策 |
| 药物相关疑问 | 记录事实，联系开方/随访医生 | 自行改剂量、停药或套用他人方案 |
| 有急性安全风险或严重反应 | 优先当地急救/危机/医疗服务 | 留在家庭讨论框架中硬扛 |

## 八步行为计划顺序

1. 积极关注
2. 以关注强化配合
3. 有效、简短、可执行的指令
4. 练习成人忙碌时不打扰
5. 代币/积分制度
6. 有限、可预期的建设性后果
7. 谨慎扩展计时隔离
8. 把规则和预案带到公共场所

**判断规则**：如果前 1–3 步尚不稳定，不要把第 6–7 步当作主要工具。

## 外部化执行功能

| 难点 | 支持 |
| --- | --- |
| 忘记下一步 | 任务卡、图片清单、物品固定位置 |
| 感觉不到时间 | 可见倒计时、两分钟预告、分段截止时间 |
| 任务过大 | 拆成 5–15 分钟可完成的第一步 |
| 容易分心 | 减少干扰、短工作段、即时回到任务提示 |
| 只盯眼前奖励 | 把远期目标拆到今天/明天，并给近端反馈 |

## 家校目标写法

使用“在何时何地，做什么，可如何观察”：

- 不佳：“上课认真一点。”
- 较好：“在 20 分钟独立练习中，开始前复述任务；收到一次提示后回到题目；完成 8 题中的 6 题。”

## 与医生讨论药物的最小问题集

1. 这项选择要改善的具体目标是什么？
2. 预期获益、常见风险和需要立即联系医生的情况是什么？
3. 如何记录效果与副作用、多久随访？
4. 既往病史、其他药物或补充剂会怎样影响判断？
5. 若效果不足或不耐受，下一步由谁、何时评估？

不根据本表自行决定开始、调整或停止任何药物。
