# 附录3：给家长的说明信

## Core Idea

班级采用正面管教时，学校需要向家长解释：这不是降低标准或放弃纪律，而是用尊重、参与和解决问题训练长期能力。家校理解一致，孩子更容易把课堂技能迁移到家庭和其他群体。

## Communication Points

说明信可以包含：

- 班会的目的：感谢、倾听、沟通、角色扮演和共同解决问题。
- 为什么减少惩罚、羞辱和公开比较。
- 七项重要技能：理解行为目的、把错误当学习机会、鼓励、尊重、自我调整、坚持，以及使用班会等结构。
- 家长如何支持：询问孩子学到的解决方案，鼓励表达感受，关注努力，必要时与教师沟通。
- 家长可参观或了解班级流程的方式。

## Tone

说明应具体、透明、可验证，不承诺“从此没有问题”。可以承认学习新方式需要时间，也说明安全、反复伤害和重大边界仍由成人负责。

## Key Takeaways

1. 家长需要知道正面管教的标准、流程与边界。
2. 透明沟通有助于减少“学校是不是放任”的误解。
3. 家校共同使用连接、责任和解决问题语言，迁移效果更好。
