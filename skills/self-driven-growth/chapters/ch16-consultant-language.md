# 实践篇·第2章：使用顾问型家长的语言

## Core Idea

顾问型语言把权力从“我命令你”转向“我相信你能思考，并愿意在你需要时支持”。它减少唠叨、说教与救场，同时让责任真正回到孩子身上。

## Frameworks Introduced

- **改变能量**：父母有力量，但不把力量强加为控制；用影响力邀请孩子行动。
  - When to use：想催促、纠正或替孩子解决问题时。
  - How：先说明观察与关切；询问孩子目标；征求给建议的许可；让他选下一步。
- **不救场原则**：让孩子承担可承受的自然结果，并在复盘时提供支持。
  - When to use：忘带东西、拖延、与同伴的普通摩擦等非安全问题。
  - How：预先说明成人能做与不会做什么，避免在危机时临时惩罚。

## Key Concepts

- **责任**：不是被羞辱后服从，而是知道选择与后果的关系并能修复。
- **说教**：成人单向输出“正确答案”，常被孩子体验为不信任。
- **许可式建议**：先问“你愿意听听我的想法吗？”。

## Anti-patterns

- **唠叨循环**：重复提醒让父母越来越像监督者，孩子越来越像被管理对象。
- **替孩子善后**：剥夺实践计划、求助和补救的机会。

## Worked Example

孩子忘了带体育用品。成人不冲去学校补送，而是平静确认：“这听起来会很麻烦。你想自己和老师说明，还是一起想怎么说明？”晚上再讨论他下次想用清单、固定放置点还是其他办法。

## Key Takeaways

1. 顾问语言要与真实的责任边界一致。
2. 先获许可再建议，能保留孩子的主体性。
3. 不救场不是不支持，而是支持孩子自己解决。
