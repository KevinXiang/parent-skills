# 棘手问题回答原则

`to-child` 解释模式核心。棘手类 = 死亡、身体与性、暴力与新闻、公平、金钱、家庭变故、"老师/大人为什么可以 XX"。

## 四原则(不可违反)

1. **先问后答**:回答之前先弄清孩子为什么问、已经知道什么。"人为什么会死"背后可能是宠物去世、同学的话、怕失去父母——回答他的真实问题,不回答你想象中的问题。
   - ✅ "你怎么想到这个的呀?""你知道些什么啦?"
2. **不撒谎**:不编"睡着了""去很远的地方了"。给孩子的版本可以简单,但不能是假的——孩子迟早会发现,损失的是信任。承受不了真相的是大人,不是孩子。
3. **按年龄分层给真相**:同一问题,给多少真相由年龄定(`ages.md`)。问什么答什么,不主动超纲,不一刀切"长大就懂了"。
4. **允许"我们一起查"**:不知道就说不知道,并示范怎么找答案。"我也不会,我们可以一起查"本身就是重要的教育。

## 常见棘手问题要点(5-9 岁)

### 死亡

- 先弄清触发(先问后答),再决定深度。
- 用具体解释:"身体停止工作了,不会再疼,也不会再醒来";**不说"睡着了"**(睡眠恐惧)。
- 允许悲伤,可以说"我也会想他"。
- 反复问同一个问题是正常的,是在反复确认,耐心答同一答案。

### "我是从哪来的"/身体

- 先问孩子自己的版本("你觉得呢?")——他可能只想要"从妈妈肚子里"这个级别的答案。
- **答所问**:问"从哪来"不等于要听完整的性教育;追问到哪层,答到哪层。
- 用正确的身体名词,语气平常——孩子对尴尬的感知来自大人的反应。

### 公平类("为什么他可以我不行""这不公平")

- 先承认感受:"你觉得不公平,我理解。"
- 不假装世界绝对公平;区分"规则对大家一致"和"人和人本来就不同"。
- 能解释的解释,不能解释的就说"这是我的决定,原因是 X"——**不编理由**。

### 涉及权威("老师为什么可以 XX""大人就可以骂人吗")

- 先接情绪再谈道理("你当时很委屈吧")。
- **不和大人立场打架,也不无原则护短**:规则是规则,大人的处理方式是处理方式,分开评价。
- 不在孩子面前妖魔化老师;涉及老师红线情形(体罚、羞辱)→ 按 `red-lines.md` 的核实谈话处理。

### 家庭变故(离婚、搬家、失业、亲人离世)

- 用孩子能懂的话告知**确定的部分**;不确定的不承诺("以后都会好的"❌)。
- 明确"不是你的错"——孩子会自动归因到自己身上。
- 尽量保持日常节奏稳定(作息、仪式),这是安全感的锚。

## 输出格式

给家长的产出是**回答脚本**,不是科普讲座:

1. **开口第一句**:怎么接住问题(通常是一句反问,落实"先问后答")
2. **主体回答**:孩子听得懂的版本(按年龄)
3. **追问预案**:孩子最可能的 1-2 个追问和接法
4. **家庭价值观选择点**(如有):列出分岔,让家长自己定(如宗教、要不要提"另一个家长")
