# 实践篇·第4章：使用激励性语言帮助孩子找到自驱力

## Core Idea

激励性语言不靠空泛赞美或高压鼓励，而是帮助孩子看见自己的努力、策略、进步和兴趣，使行动重新与胜任感和心流相连。

## Frameworks Introduced

- **过程导向反馈**：具体描述投入、策略与学习，而非评价人格或天赋。
  - When to use：孩子完成、失败或犹豫挑战时。
  - How：说“你换了方法后……”而非“你真聪明”；追问他自己觉得哪里有效。
- **心流语言**：帮助孩子识别何时挑战刚好、何时过难或过易。
  - When to use：设计练习、兴趣活动和学习支持时。
  - How：共同调整难度、时间块和反馈频率，让孩子保有选择。

## Key Concepts

- **胜任感**：相信练习能带来能力增长。
- **固定型标签**：如“你天生不擅长”，会让孩子回避失败。
- **努力策略**：可观察、可改变的做法，而非抽象“更努力”。

## Anti-patterns

- **空泛表扬**：孩子难以从“你最棒”知道下次怎么做。
- **把努力神圣化**：无效地死扛不是美德，调整方法和休息也属于努力。

## Worked Example

孩子完成一道难题。成人说：“你卡住后去画图、又检查了条件，最后找到了路。哪一步最有用？”若孩子说题太难，再一起讨论是拆小、换资料还是先休息，而不是要求他硬撑。

## Key Takeaways

1. 描述过程，邀请孩子自我评价。
2. 好的激励让孩子更理解自己，而非更依赖成人评价。
3. 匹配难度比单纯提高要求更能促进投入。
