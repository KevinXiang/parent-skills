# 术语表

**ICPS／我能解决问题** — I Can Problem Solve；以人际问题解决思维来培养社会能力的方法（全书）。

**不同的办法** — 与已提方法在策略类别上不同，而不只是换一个对象或措辞（Ch 5）。

**公平／不公平** — 同时考虑自己和他人的机会、权利与感受；不等于机械地每次完全一样（Ch 4）。

**后果** — 某个行动之后可能发生的事，以及这些事给自己和他人带来的感受（Ch 6）。

**合适的时间／地点** — 判断请求或行为是否适时、适地的概念；用于预防问题而非只在事后责备（Ch 4, 8）。

**假设性问题** — 用玩偶、图画或故事提出的低威胁练习情境；适合开始练习多种办法（Ch 5）。

**看、听、问** — 了解他人感受的三种路径：观察表情和动作、听声音与话语、直接询问（Ch 3）。

**可能／或许** — 表示对别人想法、感受或结果的不确定性；提醒孩子不猜测成事实，并去询问（Ch 4）。

**沮丧** — 想要的事没有按期望实现，或无法做到想做的事时可能出现的感受（Ch 3）。

**骄傲** — 完成有挑战的事、取得成果或做出自己认可的努力时的感受（Ch 3）。

**人际问题** — 牵涉至少一人的需要、愿望、权利或感受，并需要协调的日常处境（全书）。

**实质相同的办法** — 表面不同、核心策略相同的方案，例如“告诉妈妈”和“告诉爸爸”都属于向成人求助（Ch 5）。

**四步 ICPS 对话** — 明确问题、理解感受、想办法、预估后果的完整对话结构（Ch 1, 6）。

**小对话** — 用已学概念在日常情境中做的短练习；它为完整问题解决做准备（Ch 2–4）。

**字词游戏** — 将解决问题所需概念放入玩耍、故事和日常对话的练习方式（Ch 2, 4, 7）。

**问题澄清** — 先弄清孩子认为的问题与实际事实，而不直接从成人的指责或结论开始（Ch 1, 5）。
