# 第6章：关注解决方案

## Core Idea

正面管教把注意力从“追究过去的代价”转向“现在如何修复、下次如何做”。高质量解决方案不是成人单方面宣布的处置，而是让受影响的人参与，经过头脑风暴、筛选与实践。孩子失去理性思考能力时，应先恢复平静，再解决问题。

## Frameworks Introduced

### 3R1H 标准

解决方案要同时满足：Related（相关）、Respectful（尊重）、Reasonable（合理）、Helpful（有帮助）。它还应适合孩子年龄与技能，不把成人不便全部转嫁给孩子。

### 解决问题流程

1. 描述问题，不贴标签。
2. 让每个受影响的人说出感受与需要。
3. 共同头脑风暴，不立即评价。
4. 删除伤害性、不可行或不相关的方案。
5. 让受影响的孩子选择可接受方案。
6. 约定何时试行，之后复盘并调整。

### 积极暂停

暂停不是隔离、羞辱或强制反省，而是帮助人恢复理性。暂停空间由家庭或班级预先共同设计，可以有舒适物、书、纸笔或安静活动。双方平静后仍要完成解决与修复。

## Heuristic Questions

可用问题包括：发生了什么？你想要什么？当时感受如何？为什么会这样？你学到了什么？下次怎样运用？你想到什么解决办法？问题应帮助孩子思考，不应暗藏成人预设答案。

## Key Concepts

- “先连接再纠正”不是拖延，而是为思考创造条件。
- 头脑风暴阶段允许暂时不成熟的想法，筛选阶段再讨论可行性。
- 受影响的人越多，越需要保证每个人都有表达机会。
- 复盘比一次完美解决更重要；孩子需要多次练习。

## Anti-patterns

- 用“你为什么这么做”追问成审讯。
- 先讲一大段道理，再假装让孩子选择。
- 在孩子哭喊、攻击或成人暴怒时强迫讨论。
- 让解决方案变成新的惩罚。

## Worked Example

两个孩子争同一个玩具。成人先确保安全：“我不会让你们互相打。”待平静后分别问他们想要什么，再让他们提出方案：轮流计时、一起玩、换一个物品、暂时收起。成人删除会伤害他人的方案，让孩子选择并约定计时方式；若失败，下一次会议复盘，而不是宣布谁是坏孩子。

## Key Takeaways

1. 先恢复思考能力，再解决问题。
2. 让孩子参与方案形成，才能训练判断与责任。
3. 用 3R1H 检查方案，而不是用成人权威检查服从。
